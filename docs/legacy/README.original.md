# OSISOS

OSISOS is a modular, resource-constrained Linux-based operating environment that exposes core operating-system functionality through a unified abstraction layer.

## Targets
- ~32 MB RAM
- ~300 MHz-class CPU (1 constrained vCPU)
- Small storage footprint

## Build Instructions
1. `mkdir build`
2. `cd build`
3. `cmake ..`
4. `make`

## Execution
Run the shell with:
`./osisos`
